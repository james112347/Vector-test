    1. Create the Vite project using the React TypeScript template:
       ```bash
       npm create vite@latest vector-app -- --template react-ts
       ```
       Then move all generated files into the repo root (not a nested directory). If creating in current directory, adjust accordingly.

    2. Install core dependencies:
       ```bash
       npm install react-router-dom dexie dexie-react-hooks
       ```

    3. Install PWA dependencies:
       ```bash
       npm install -D vite-plugin-pwa
       ```

    4. Install Tailwind CSS v4 (uses the new Vite plugin approach):
       ```bash
       npm install -D tailwindcss @tailwindcss/vite
       ```

    5. Install shadcn/ui prerequisites and initialize:
       ```bash
       npx shadcn@latest init --defaults
       ```
       Accept defaults. This sets up the component system with Tailwind.

    6. Install dev tools:
       ```bash
       npm install -D eslint prettier eslint-config-prettier
       ```

    7. Update `index.html` to include a dark mode flash prevention script in the `<head>` BEFORE any other scripts:
       ```html
       <script>
         (function() {
           var theme = localStorage.getItem('theme');
           if (theme === 'dark' || (!theme && window.matchMedia('(prefers-color-scheme: dark)').matches)) {
             document.documentElement.classList.add('dark');
           }
         })();
       </script>
       ```
       Also set `<html lang="en">` and update `<title>` to "Vector - Energy Tracker".

    8. Update `src/App.tsx` to render a minimal placeholder:
       ```tsx
       function App() {
         return (
           <div className="min-h-screen bg-background text-foreground flex items-center justify-center">
             <h1 className="text-2xl font-bold">Vector</h1>
           </div>
         );
       }
       export default App;
       ```

    9. Update `src/main.tsx` to be a clean entry point (service worker registration added in Task 2):
       ```tsx
       import React from 'react';
       import ReactDOM from 'react-dom/client';
       import App from './App';
       import './index.css';

       ReactDOM.createRoot(document.getElementById('root')!).render(
         <React.StrictMode>
           <App />
         </React.StrictMode>
       );
       ```

    10. Verify project builds and dev server starts:
        ```bash
        npm run build
        npm run dev -- --host
        ```

  <action>
    1. Update `vite.config.ts` with the VitePWA plugin configuration:
       ```typescript
       import { defineConfig } from 'vite';
       import react from '@vitejs/plugin-react';
       import tailwindcss from '@tailwindcss/vite';
       import { VitePWA } from 'vite-plugin-pwa';

       export default defineConfig({
         plugins: [
           react(),
           tailwindcss(),
           VitePWA({
             registerType: 'prompt',
             includeAssets: ['icons/*.png', 'robots.txt'],
             manifest: {
               name: 'Vector - Energy Tracker',
               short_name: 'Vector',
               description: 'Track your physical, mental, and emotional energy',
               theme_color: '#1e40af',
               background_color: '#0f172a',
               display: 'standalone',
               start_url: '/',
               orientation: 'portrait',
               categories: ['health', 'lifestyle', 'productivity'],
               icons: [
                 {
                   src: 'icons/icon-192.png',
                   sizes: '192x192',
                   type: 'image/png',
                 },
                 {
                   src: 'icons/icon-512.png',
                   sizes: '512x512',
                   type: 'image/png',
                 },
                 {
                   src: 'icons/icon-maskable-512.png',
                   sizes: '512x512',
                   type: 'image/png',
                   purpose: 'maskable',
                 },
               ],
             },
             workbox: {
               globPatterns: ['**/*.{js,css,html,ico,png,svg,woff2}'],
               runtimeCaching: [
                 {
                   urlPattern: /^https:\/\/fonts\.googleapis\.com\/.*/i,
                   handler: 'CacheFirst',
                   options: {
                     cacheName: 'google-fonts-cache',
                     expiration: {
                       maxEntries: 10,
                       maxAgeSeconds: 60 * 60 * 24 * 365,
                     },
                   },
                 },
                 {
                   urlPattern: /\.(?:png|jpg|jpeg|svg|gif|webp)$/,
                   handler: 'CacheFirst',
                   options: {
                     cacheName: 'image-cache',
                     expiration: {
                       maxEntries: 50,
                       maxAgeSeconds: 60 * 60 * 24 * 30,
                     },
                   },
                 },
               ],
             },
           }),
         ],
         resolve: {
           alias: {
             '@': '/src',
           },
         },
       });
       ```

    2. Update `src/main.tsx` to register the service worker with update prompt:
       ```typescript
       import React from 'react';
       import ReactDOM from 'react-dom/client';
       import { registerSW } from 'virtual:pwa-register';
       import App from './App';
       import './index.css';

       const updateSW = registerSW({
         onNeedRefresh() {
           if (confirm('New version available! Reload to update?')) {
             updateSW(true);
           }
         },
         onOfflineReady() {
           console.log('Vector is ready to work offline');
         },
       });

       ReactDOM.createRoot(document.getElementById('root')!).render(
         <React.StrictMode>
           <App />
         </React.StrictMode>
       );
       ```

    3. Generate placeholder PWA icons. Use a simple script or canvas approach to create solid-colored placeholder icons. The icons should be a calming blue (#1e40af) square with a white "V" letter in the center. Generate three files:
       - `public/icons/icon-192.png` (192x192)
       - `public/icons/icon-512.png` (512x512)
       - `public/icons/icon-maskable-512.png` (512x512 with extra safe-zone padding for maskable)

       If canvas generation is not available, create minimal valid PNG files as placeholders. The important thing is they exist and are valid PNG files of the correct dimensions. You can use a Node.js script with the `canvas` package, or generate SVG files and reference those, or simply download placeholder images.

       A practical approach: create a small Node.js script that generates the PNGs, run it, then delete the script. Or use `npx` to leverage a tool. If that fails, create minimal 1x1 PNGs and note that real icons should be designed later.

    4. Create `public/robots.txt`:
       ```
       User-agent: *
       Allow: /
       ```

    5. Add TypeScript type declaration for the virtual PWA register module. In `src/vite-env.d.ts`, ensure it includes:
       ```typescript
       /// <reference types="vite/client" />
       /// <reference types="vite-plugin-pwa/client" />
       ```

    6. Run `npm run build` and verify:
       - Build succeeds
       - `dist/` contains `manifest.webmanifest`
       - `dist/` contains a service worker file (sw.js or similar)
       - Icons exist in `dist/icons/`
